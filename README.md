# HOLIDAY-OVERTIME-CALCULATOR

==================================================
   PHILIPPINE HOLIDAY & OVERTIME PAY CALCULATOR
==================================================

VERSION: 1.0
PLATFORM: Windows / Mac / Android
BROWSER: Google Chrome, Microsoft Edge, Firefox

--------------------------------------------------
1. DESCRIPTION
--------------------------------------------------

This is an HTML-based calculator designed to
calculate holiday pay and overtime pay based on
Philippine holiday pay multipliers.

The calculator supports:

- Regular Holiday (200%)
- Regular Holiday + Rest Day (260%)
- Special Non-Working Holiday (130%)
- Special Holiday + Rest Day (150%)

It automatically calculates:

- Hourly Basic Rate
- Holiday Pay
- Overtime Pay
- Total Hours Worked
- Total Holiday and Overtime Compensation

--------------------------------------------------
2. INSTALLATION
--------------------------------------------------

No installation is required.

1. Save the HTML file as:

   Holiday_Overtime_Calculator.html

2. Locate the saved HTML file.
3. Double-click the file.
4. Open it using Google Chrome or Microsoft Edge.
5. The calculator is ready to use.

An internet connection is NOT required.

--------------------------------------------------
3. HOW TO USE
--------------------------------------------------

STEP 1:
Enter your Daily Basic Wage.

Example: PHP 600.00

STEP 2:
Select the applicable Holiday Type.

STEP 3:
Enter the Total Hours Worked.

Example: 10 hours.

STEP 4:
The calculator automatically displays:

- Hourly Basic Rate
- Holiday Rate
- Overtime Rate
- Regular Hours
- Overtime Hours
- Holiday Pay
- Overtime Pay
- TOTAL PAY

STEP 5:
Click RESET CALCULATOR to restore the
default sample values.

--------------------------------------------------
4. COMPUTATION FORMULAS
--------------------------------------------------

Hourly Basic Rate:

Daily Basic Wage / 8

Holiday Pay:

Hourly Basic Rate x Holiday Multiplier
x Regular Hours Worked

Overtime Pay:

Hourly Basic Rate x Overtime Multiplier
x Overtime Hours Worked

Total Pay:

Holiday Pay + Overtime Pay

--------------------------------------------------
5. HOLIDAY MULTIPLIERS
--------------------------------------------------

Regular Holiday:
Regular Work = 200%
Overtime = 260%

Regular Holiday + Rest Day:
Regular Work = 260%
Overtime = 338%

Special Non-Working Holiday:
Regular Work = 130%
Overtime = 169%

Special Non-Working Holiday + Rest Day:
Regular Work = 150%
Overtime = 195%

--------------------------------------------------
6. SAMPLE COMPUTATION
--------------------------------------------------

Daily Basic Wage: PHP 600.00
Holiday Type: Regular Holiday
Total Hours Worked: 10 hours

Hourly Basic Rate: PHP 75.00

First 8 Hours:
PHP 75 x 200% x 8
= PHP 1,200.00

2 Hours Overtime:
PHP 75 x 260% x 2
= PHP 390.00

TOTAL PAY:
PHP 1,590.00

--------------------------------------------------
7. IMPORTANT NOTES
--------------------------------------------------

- The calculator assumes an 8-hour normal
  workday.
- Hours beyond 8 are treated as overtime.
- This computation excludes separate unworked
  holiday pay entitlement.
- Night shift differential, allowances,
  deductions, and other applicable premiums
  are not included.
- Actual employee entitlements depend on
  applicable Philippine labor regulations
  and individual circumstances.
